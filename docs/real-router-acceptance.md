# 真机验收清单

## 1. 离线模拟

- 前后端构建与单元测试全部通过。
- 域名清洗、Punycode、精确/整站、冲突、标记块和 UCI 段解析通过。
- 使用脱敏样本覆盖空文件、已有注释、重复规则和破损标记。

## 2. 真实路由器只读识别

- 由设备所有者明确指定软路由并提供 SSH 权限。
- 首次核对主机指纹，仅执行发行版、软件包、UCI、服务、进程和核心版本读取。
- 确认正确选择唯一运行插件；多个插件同时运行时由用户手动选择。
- 将页面数量、原始顺序和启用状态与 OpenClash/Nikki 自定义规则界面对照。
- OpenClash 核对专用自定义规则文件修改时间不变；Nikki 核对相关 UCI 内容在读取前后不变。
- Nikki 如存在 `nikki-rules` 混入文件，只确认软件显示“存在混入文件规则，本版本未展开”，不得读取或导出文件内容。
- 导出脱敏诊断并扫描密码、订阅 URL 和节点信息。

## 3. 经用户再次确认后的写入闭环

对 OpenClash 和 Nikki 分别执行：

1. 创建 `www.baidu.com` 精确直连规则。
2. 确认订阅规则前方出现助手规则，服务和核心 API 正常。
3. 重启插件并确认规则仍存在。
4. 更新订阅并确认助手规则未被覆盖。
5. 删除该规则，确认只移除助手管理内容。
6. 完成一次备份恢复，并确认原服务状态恢复。
7. 模拟 SSH 断开或验证失败，确认 120 秒内看门狗自动恢复。

整个验收期间不得写入 DNS、DHCP、防火墙或 SmartDNS 配置。
