# 真机验收清单

## 1. 离线模拟

- 前后端构建与单元测试全部通过。
- 域名清洗、Punycode、精确/整站、冲突、标记块和 UCI 段解析通过。
- 使用脱敏样本覆盖空文件、已有注释、重复规则和破损标记。

## 2. 真实路由器只读识别

- 由设备所有者明确指定软路由并提供 SSH 权限。
- 首次核对主机指纹，仅执行发行版、软件包、UCI、服务、进程和核心版本读取。
- 核对 OpenClash、Nikki、HomeProxy、PassWall/PassWall2 的检测数量和运行状态；未支持插件不得读取配置。
- 确认唯一运行的受支持插件自动选中；OpenClash 与 Nikki 同时运行时必须由用户手动选择，且风险提示持续显示。
- 运行中的 HomeProxy、PassWall/PassWall2 必须持续显示风险提示，但不得阻止用户修改明确选中的 OpenClash/Nikki；确认软件没有启动、停止或重载未选插件。
- 切换当前管理对象后，旧插件的规则、策略组、预览和验证结果必须全部清空。
- 将页面数量、原始顺序和启用状态与 OpenClash/Nikki 自定义规则界面对照。
- OpenClash 核对专用自定义规则文件修改时间不变；Nikki 核对相关 UCI 内容在读取前后不变。
- Nikki 如存在 `nikki-rules` 混入文件，只确认软件显示“存在混入文件规则，本版本未展开”，不得读取或导出文件内容。
- 导出脱敏诊断并扫描密码、订阅 URL 和节点信息。
- 打开 DNS 防污染页面，只读核对 OpenClash DNS 启用状态、加密/明文上游数量、增强模式及局域网 DNS 入口；不得误读取其他插件的 Mihomo 配置。
- 核对“推荐链路”明确标注为示意；配置不可读时加密/明文数量必须显示“未知”，不能显示为 0。
- 将“当前 Windows 电脑”链路与 `ipconfig /all` 或系统网卡设置对照，核对活动网卡、IPv4/IPv6 DNS 和默认网关；连接 VPN/Tailscale 或设置外部 DNS 时必须出现“可能绕过”提示。
- 将“软路由内部”链路与实际 dnsmasq、OpenClash、AdGuard Home、SmartDNS、mosdns 配置逐项对照；节点应注明证据等级，不得返回上游 URL、认证字段或完整配置。
- 百度/Google 解析观测只验收成功、失败和耗时表达，不得把成功文案解释为已证明使用 DoH。

## 3. 经用户再次确认后的写入闭环

对 OpenClash 和 Nikki 分别执行：

1. 创建 `www.baidu.com` 精确直连规则。
2. 确认订阅规则前方出现助手规则，服务和核心 API 正常。
3. 重启插件并确认规则仍存在。
4. 更新订阅并确认助手规则未被覆盖。
5. 删除该规则，确认只移除助手管理内容。
6. 完成一次备份恢复，并确认原服务状态恢复。
7. 模拟 SSH 断开或验证失败，确认 120 秒内看门狗自动恢复。

对 OpenClash DNS 防污染另执行一次经确认的闭环：生成中文预览，核对只新增助手 DNS 标记块；应用后百度与 Google 解析均通过，随后用备份恢复并确认原有覆写脚本、UCI 和服务状态恢复。

除上述明确确认的 OpenClash 助手 DNS 标记块外，整个验收期间不得写入 dnsmasq、DHCP、防火墙、SmartDNS、AdGuard Home、订阅或节点配置。
